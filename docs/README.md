# Catalyst Documentation Site

Official documentation for the Catalyst platform - built with Nextra.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Visit [http://localhost:3006](http://localhost:3006)

## 📦 Build & Deploy

```bash
npm run build
npm start
```

## 🌐 Deploy to Vercel

1. Push to GitHub
2. Import to Vercel
3. Auto-deploys on push

## 📁 Structure

- `pages/` - All documentation pages
- `theme.config.js` - Theme customization
- `public/` - Static assets

## 🛠️ Tech Stack

- Next.js 14
- Nextra 3.x
- TypeScript
- Tailwind CSS
